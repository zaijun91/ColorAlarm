# ColorAlarm

基于摄像头画面的浏览器颜色变化监测工具。选取画面中的监控点，以选点时的颜色为基准；颜色差异超过阈值时显示报警状态、记录日志并尝试播放声音。

## 功能

- 直接在摄像头画面上设置多个监控点。
- 每 500 毫秒比较监控点的当前颜色与初始颜色，使用 Lab 色彩空间中的 Delta E 距离。
- 可调报警阈值，默认 30；数值越小，对颜色变化越敏感。
- 监控点异常时显示红框，恢复时回到绿框，并记录带时间的日志。
- 监控点由正常进入报警状态时播放 `alarm.wav`；持续异常不会在每次检查时重复触发声音。

## 本地运行

这是纯静态 HTML、CSS 和 JavaScript 项目，无需安装 npm 依赖或构建。需要摄像头，以及支持 `getUserMedia` 的现代浏览器。

1. 克隆或下载本仓库，进入包含 `index.html` 的目录。
2. 安装 Python 3 后，在该目录启动本地静态服务器：

   ```sh
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

   Windows 上也可使用 `py -3 -m http.server 8000 --bind 127.0.0.1`。

3. 打开 <http://localhost:8000>，允许浏览器使用摄像头。

摄像头需要安全上下文：本地使用 `localhost`，远程站点使用 HTTPS。不要通过普通远程 HTTP 地址运行；如果摄像头不可用，请检查系统与浏览器权限、设备是否被其他应用占用。

## 使用步骤

1. 等待摄像头画面加载和成功日志出现。
2. 点击 **设置监控点**，再点击画面中需要观察的位置；每次点击都会保存该位置当时的颜色。
3. 点击 **完成选择**。至少选择一个点后，才能开始监控。
4. 设置 **报警灵敏度 (Delta E)**，点击 **开始监控**。观察点位颜色、运行日志和声音提醒。
5. 点击 **停止监控** 后可继续添加监控点；如需重新校准所有基准颜色，点击 **清除所有点** 后重新选点。停止监控不会关闭摄像头，关闭页面可结束本次使用。

## 限制与数据处理

- 监测的是固定坐标上的单个像素，不会跟踪物体；光照变化、摄像头移动和画面噪声都可能触发报警。
- 页面需保持打开；后台标签页、设备休眠和浏览器节流可能影响检查频率。
- 声音播放受浏览器音频策略和设备音量影响。实际使用前，请手动改变监控点颜色，确认日志和声音都符合预期。
- 当前代码在浏览器内处理摄像头画面，没有上传画面或保存监控点、日志的功能；刷新页面会清除本次点位和日志。
- 目前没有自动化摄像头或音频行为测试，静态检查通过不代表设备上的交互行为已验证。

## 文件与检查

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构及本地资源引用 |
| `style.css` | 页面样式 |
| `script.js` | 摄像头、选点、颜色比较和报警逻辑 |
| `alarm.wav` | 页面实际引用的报警音频 |
| `alarm.mp3` | 仓库保留的另一音频文件，当前页面未引用 |
| `.github/workflows/static-checks.yml` | JavaScript 语法和本地页面资源检查 |

安装 Node.js 24 后，可在仓库根目录进行语法检查：

```sh
node --check script.js
```

GitHub Actions 在推送和拉取请求时执行上述检查，并确认 `index.html` 引用的本地样式、脚本、音频等文件存在且非空。工作流仅申请仓库内容读取权限，不执行部署。

## 关于旧部署脚本

**请勿直接运行 `deploy.bat`。** 该历史脚本会删除本地 `.git` 目录、重新初始化仓库，并向旧地址 `zaijun91/ColorAlarm-1` 推送，最后删除脚本自身；它不适用于维护当前仓库。

如需托管，只需将页面及其引用的静态资源发布到提供 HTTPS 的静态站点服务。本仓库目前没有在此文档中声明已验证的在线演示地址。
